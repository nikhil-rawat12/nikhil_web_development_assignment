Basic Mathematics Formulas

Algebra

Square of a variable: y2 = y × y

Cube of a variable: y3 = y × y × y

(x + y)2 = x2 + 2xy + y2

(x - y)2 = x2 - 2xy + y2

x2 - y2 = (x + y)(x - y)

Geometry

Circle area = πr2

Circle circumference = 2πr

Triangle area = 1/2 × base × height

Right triangle formula: p2 + q2 = r2

Mensuration

Rectangle area = length × width

Rectangle perimeter = 2 × (length + width)

Cube volume = side3

Cuboid volume = length × width × height

Square area = side2

Mathematical Notation using Subscript

Water = H2O

Carbon dioxide = CO2
